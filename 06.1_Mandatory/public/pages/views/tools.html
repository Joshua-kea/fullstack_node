Tools I have used in full stack Node.js class

Express

Express is the library used to build the server in Node.js. It makes it possible to create routes, that receive a request and send a response.

NPM

NPM is the build tool for Node.js and is similar to Maven.

It is used to install packages and run scripts listed in package.json.

Git/GitHub

Git keeps track of code changes, and GitHub is a website where the code can be saved online.

Postman

Postman is used to test servers without a frontend. It can take HTTP methods such as GET and POST and an endpoint, and then show the response.

Postman can also be used for debugging, as it shows the status code and response.

Browser DevTools

The DevTools in the browser show errors and messages in the console. You can also find network information, to see the status code.

Linters & formatters

A linter checks the code for mistakes, without running it. For example it might catch an undefined variable. ESLint is a common linter for JavaScript.

Prettier is a common formatter, which automatically formats the code when saving.
