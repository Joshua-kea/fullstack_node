Arrays & Loops

The three rules of Loops:

  • Use loop methods in JavaScript.
  • Don't use for-loops, unless you're finger counting.
  • Use .map if you need the data afterwards. Only use .forEach if you don't need the data.

Avoid using .forEach. Avoid side effects, as we do not wish to affect old data.
There are several different loop methods:

Loop method Description
.forEach For every x, do x.
.map returns a new list of the same size. It is 1:1.
.filter Works like a sieve. True goes through, false gets filtered away.
It is possible to change the values with .filter
.reduce Takes two values (accumulator and current) and turns it into one value.
Can also be described as folding.
.find Finds the first element that matches. Returns -1 if it doesn't find anything.
.findIndex Finds out which index the element is on.
.indexOf Finds the element, even though you don't know the exact index.
