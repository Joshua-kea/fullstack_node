Arrays & Loops

The three rules of loops

  • Use loop methods in JavaScript.
  • Don't use for-loops, unless you're finger counting.
  • Use .map if you need the data afterwards. Only use .forEach if you don't need the data.

Avoid side effects, as we do not wish to affect old data. You can read more about side effects on the fundamentals page.

Loop methods

Loop method Description
.forEach For every x, do y. It doesn't return anything.
.map Returns a new list of the same size. It is 1:1.
.filter Works like a sieve. True goes through, false gets filtered away.
.find Finds the first element that matches.
.findIndex Finds the index of the first matching element. Returns -1 if it doesn't find anything.
.indexOf Finds the index of a specific value. Returns -1 if it doesn't find anything.
.reduce Takes two values (accumulator and current) and combines the current value with the accumulator.
Can also be described as folding.

Examples of usage

Example of .forEach() method

const flags = [
  { country: "Benin", colors: ["green", "yellow", "red"] },
  { country: "Nauru", colors: ["blue", "yellow", "white"] },
  { country: "Comoros", colors: ["green", "white", "red", "yellow", "blue"] },
  { country: "Suriname", colors: ["green", "white", "red", "yellow"] },
];

function logCountry(flag) {
  console.log(`The flag of ${flag.country}`);
}

flags.forEach(logCountry);

// output would be:
// The flag of Benin
// The flag of Nauru
// The flag of Comoros
// The flag of Suriname

Example of .map() method

function amountOfFlagColors(flag) {
  return `${flag.country} has ${flag.colors.length} colors`;
}

const flagColorSummaries = flags.map(amountOfFlagColors);

console.log(flagColorSummaries);

// output would be:
// ["Benin has 3 colors", "Nauru has 3 colors", "Comoros has 5 colors", "Suriname has 4 colors"]

Example of .filter() method

function hasRed(flag) {
  return flag.colors.includes("red");
}

const flagsWithRed = flags.filter(hasRed);

console.log(flagsWithRed);

// output would be:
// [
//  { country: "Benin", colors: ["green", "yellow", "red"] },
//  { country: "Comoros", colors: ["green", "white", "red", "yellow", "blue"] },
//  { country: "Suriname", colors: ["green", "white", "red", "yellow"] },
// ]

Example of .find(). The difference between .find() and .filter(), is that .find() stops at the first element that matches the criteria, whereas .filter() returns a list of all that match the criteria. 

const flagWithRed = flags.find(hasRed);

console.log(flagWithRed);

// output would be: 
// { country: "Benin", colors: ["green", "yellow", "red"] }

Example of .findIndex(). Similar to .find(), .findIndex() only returns the index of the first element that matches the criteria. 

const redFlagIndex = flags.findIndex(hasRed);

console.log(redFlagIndex);
// output would be: 
// 0 
// Benin is the first match, and is indexed at 0.

Example of .indexOf()

const surinameColors = flags[3].colors;

console.log(surinameColors.indexOf("red"));
// output would be:
// 2
// The Suriname object is: 
// { country: "Suriname", colors: ["green", "white", "red", "yellow"] }
// so the color red is indexed at 2

console.log(surinameColors.indexOf("blue"));
// output would be:
// -1

The .reduce() method can be a bit confusing, so I've tried to break it down a bit more clearly. Let's imagine you have a webshop with a cart. You have 4 items in your cart, and you wish to calculate the full price of the cart. 

const cart = [20, 15, 30, 10]; // prices of the individual items in your cart

// total is the accumulator
function calculateCartTotal(total, itemPrice) {
  return total + itemPrice;
}

const cartTotal = cart.reduce(calculateCartTotal, 0);

// it goes through every item one at a time
// total starts out being 0, the first itemPrice is 20, so the total is now 20
// now the total is 20, the next itemPrice is 15, so the total becomes 35
// now the total is 35, the next itemPrice is 30, so the total becomes 65
// now the total is 65, the next itemPrice is 10, so the total becomes 75

console.log(cartTotal);
// output would be:
// 75

Array methods

Array method Description
.push() Adds an element to the end of the array
.pop() Removes the last element of the array
.unshift() Adds an element to the front of the array
.shift() Removes the first element of the array

Examples of usage

Example of .push()

const colors = ["red", "blue", "green"];

console.log(colors);
// output would be:
// ["red", "blue", "green"]

colors.push("yellow");

console.log(colors)
// output would be:
// ["red", "blue", "green", "yellow"]

Example of .pop()

const colors = ["red", "blue", "green"];

colors.pop();

console.log(colors);
// output would be:
// ["red", "blue"]

Example of .unshift()

const colors = ["red", "blue", "green"];

colors.unshift("yellow");

console.log(colors);
// output would be:
// ["yellow", "red", "blue", "green"]

Example of .shift()

const colors = ["red", "blue", "green"];

colors.shift();

console.log(colors);
// output would be:
// ["blue", "green"]
