Date()

New Date() returns a Date object for the current time and date. Date.now() returns the milliseconds since the Unix Epoch Time AKA the milliseconds since jan 1st 1970. The standard format for date and time is ISO 8601.

Static methods


      Date.now()

      // output will be something like: 1790940898647

This will give you the current time in Unix Epoch Time (milliseconds since January 1st 1970). 


      Date.parse("1970-01-01");

      // This exact example gives 0 as output

      Date.parse("2026-01-01");

      // Gives 1767225600000 as output

This will take a date string and give you the number of milliseconds since the Unix Epoch time 


      new Date(1970, 0, 1);

      // This exact example gives 0 as output

      new Date(2026, 0, 1);

      // Gives 1767225600000 as output

This method takes numbers as parameters and gives you the number of milliseconds since the Unix Epoch time.
Note that January is indexed at 0, not at 1.

Instance methods

The Date object has a lot of instance methods, but some of the more popular ones are: 


      const birthday = new Date("October 2 2026")

      const date = birthday.getDate();

      // output is 2, getDate() gives the date.

      birthday.getDay();

      // Sunday -> Saturday is indexed 0 - 6

      // output is 5

      birthday.getFullYear();

      // output is 2026

There are a lot more examples of .get and .set methods


        birthday.toLocaleDateString();

        // output is 2.10.2026

        birthday.toLocaleDateString("en-uk");

        // output is 2/10/2026. en-uk is the british standard. The Danish standard is da-dk.

        const options = {
          weekday: "long",
          year: "numeric",
          month: "long",
          day: "numeric",
        };

        birthday.toLocaleDateString("en-uk", options)

        // output is Friday, 2 October 2026
