Project setup

package.json

The project's packages need to be written in a package.json file as "package-name": "version". 

{
    "dependencies": {
        "express": "5.2.1"
    }
}

Using the npm init command, will create the package.json for you.

Scripts

The command npm run <script-name> runs the scripts defined in package.json. Scripts are written like shell commands and work like shell commands.

It is very common to make a "start" and "start-dev" script.

"scripts": {
    "start": "cross-env PORT=8080 node app.js",
    "start-dev": "cross-env PORT=8080 nodemon app.js"
}

cross-env is a script, and the rest are arguments. It is also called a wrapper. nodemon is also a wrapper for node, so start-dev has a wrapper around a wrapper.

cross-env makes it possible to set environment variables no matter if you are on Mac, Windows or Linux.

Environment variables

process has a lot of information about things. process.env is an object with the environment variables, which you can dot into, for example process.env.PORT. Environment variables are written in all caps with underscores. 

const PORT = process.env.PORT ?? 8080;

If PORT is not set (it is null or undefined), the port will be 8080. ?? is used in this example, because nullish coalescing is specifically for null/undefined.

Folder structure

It is important to think about the folder structure, and keep it easy to navigate both for yourself and others. 

Project_Folder
├── node_modules
├── public
│   ├── assets
│   │   ├── css
│   │   │   └── index.css
│   │   └── images
│   │       └── favicon.png
│   ├── components
│   │   ├── footer
│   │   │   └── footer.html
│   │   └── header
│   │       └── header.html
│   └── pages
│       ├── frontpage
│       │   ├── frontpage.html
│       │   └── frontpage.js
│       └── about
│           └── about.html
├── templatingEngine
│   ├── pages.js
│   └── templatingEngine.js
├── util
│   └── sharedFile.js
├── app.js
├── nodemon.json
├── package-lock.json
└── package.json

The folder util, is used for the server. It holds any file that is shared across multiple files.

The public folder is where all the publicly accessible files are. It is used for the client. To make it public you have to let express know in app.js. 

app.use(express.static("public"));

With express.static all the files in the public folder become public and can be reached with for example /frontpage.css.

Static is a security feature, so Express doesn't just serve every file. You have to tell it which ones may be served, so you can protect secret files.
