Fetch

app.get("/proxy", (req, res) => {
  fetch("https://www.google.com")
    .then((response) => response.text())
    .then((result) => res.send(result));  
});

In this example we're fetching Google.com, to create a proxy of Google.com. Google is text HTML, which is why we use .text() instead of .json(). The result is the HTML page.

If your browser settings is in a language with non-English symbols, you might get a weird looking website. A way to solve that, is by using arrayBuffer() and TextDecoder(). 

app.get("/proxy", (req, res) => {
  fetch("https://www.google.com")
    .then((response) => response.arrayBuffer())
    .then((buffer) => {
      const decoder = new TextDecoder("ISO-8859-1");
      const text = decoder.decode(buffer);
      res.send();
    })
});

This example is set to the Danish standard, so the website can show Danish symbols.
