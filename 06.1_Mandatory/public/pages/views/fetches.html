Fetch

Proxy

app.get("/proxy", (req, res) => {
  fetch("https://www.google.com")
    .then((response) => response.text())
    .then((result) => res.send(result));  
});

In this example we're fetching Google.com, to create a proxy of Google.com. Google sends HTML as text, which is why we use .text() instead of .json(). The result is the HTML page.

You might get a weird looking website. A way to solve that, is by using arrayBuffer() and TextDecoder(). 

app.get("/proxy", (req, res) => {
  fetch("https://www.google.com")
    .then((response) => response.arrayBuffer())
    .then((buffer) => {
      const decoder = new TextDecoder("ISO-8859-1");
      const text = decoder.decode(buffer);
      res.send(text);
    })
});

This example is set to the Danish standard, so the website can show Danish symbols.

API and CORS

CORS is a browser thing. If the browser fetches an API directly, the API has to allow it, and most don't (even if they say they do).

Here is an example with Plantsolve where fetch runs in the browser, in a script on the page. 

fetch("https://www.plantsolve.com/api/v1/plants/index.json");

It will be blocked and you will get a CORS error. You must fetch on the server side. Since CORS is a browser thing, it doesn't apply to servers. 

app.get("/plants", async (req, res) => {
    const response = await fetch("https://www.plantsolve.com/api/v1/plants/index.json");
    const result = await response.json();
    
    res.send({ data: result });
});

Doing it server side removes the CORS error. Note that the fetch has await, so the function needs to be async. This is added right before the callback function.

With this solution the API is only called when someone hits the "/plants" endpoint.

Slug

A slug is kind of the pathvariable for APIs. Slug is what is shown in the URL. So if you go to plants/cactus, the server knows which plant it is. 

app.get("/plants/:slug", async (req, res) => {
    const slug = req.params.slug;
    const response = await fetch(`https://www.plantsolve.com/api/v1/plants/${slug}.json`);
    const result = await response.json();

    res.send({ data: result });
});
