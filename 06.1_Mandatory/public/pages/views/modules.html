Modules

With modules you can split your JavaScript files up into several files, and use import and export to access functionality between them

Import Export
CommonJS Use require().
const file = require('./file'); 		Use module.exports
module.exports = file;
ES Modules Use import
import file from './file.js'; 		Use export or export default
export default file;

CommonJS

CommonJS is the standard module system, if it isn't actively changed to something else.

It is possible to import .json files using require().

ES Modules

To use ES Modules, you have to actively change the type in package.json

{
        "type": "module"     
}

With modules it is possible to reuse code between backend and frontend, which can be relevant for validation, for example for a login system.
