Modules

  • CommonJS
  • ES Modules

With modules you can split your JavaScript files up into several files, and use import and export to access functionality between them.

Import Export
CommonJS Use require().
const file = require('./file'); 		Use module.exports
module.exports = file;
ES Modules Use import
import file from './file.js';
import { file } from './file.js'; 		Use export or export default
export default file;
export const file = "file";

Importing and exporting functionality between .js files, is the reason to use modules.

It is important to be careful with circular dependencies, where file A imports from file B, and file B also imports from file A. That creates a circle, and in cases like that neither file can finish loading without the other, and it can cause bugs and crashes.

CommonJS

CommonJS is the default module system for Node.js, if it isn't actively changed to something else.

It is possible to import .json files using require().

const data = require('./data.json');

Frontend imports are done with a <script> tag.

<script src="/file.js"></script>

ES Modules

To use ES Modules, you have to actively change the type in package.json

{
        "type": "module"     
}

ES Modules can't import .json files in the same way as CommonJS can. The solution is using the fs library. 

import fs from 'fs';
const data = JSON.parse(fs.readFileSync('./data.json', 'utf-8'));

When using export default, the variable name doesn't matter when importing. 

// file: colors.js
const colors = ["red", "blue", "yellow", "green", "orange"];
export default colors;

// file: flags.js
import flagColors from './colors.js';
// in colors.js it is called "colors", but in flags.js I called it "flagColors"
// Any name would work. Without curly braces {}, you always import the default

Frontend imports with ES Modules, require the type set to module

<script type="module" src="/file.js"></script>

ES Modules make it possible to reuse code between backend and frontend, which can be relevant for validation, for example for a login system.
