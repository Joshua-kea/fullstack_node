Express & Servers

Express and app.js

The library Express needs to be imported to build a server in Node.js.

const express = require('express');
const app = express();

If you're using ES Modules, the import works differently.

import express from 'express';
const app = express();

app.listen() must always be at the bottom of the app.js file.

const PORT = 8080;
app.listen(PORT, (error) => {
  if (error) {
    console.log("There was an error starting the server", error);
  }
  console.log("Server is running on port", PORT);
});

Client/Server and routes

Client sends a request (shortened to req), server sends a response (shortened to res). Use res.send(); to send a response back to the client. We use a generic data-type to send data. 

app.get('/', (req, res) => {
  res.send({ data: "Hello, how are you?" });
});

The example above is called a route. '/' is the endpoint, it could also have been '/flags' for example. (req, res) => {} is an example of a callback function. Learn more about callback functions here

res.send() sends a JavaScript object, which is parsed into json by the help of express. Without res.send(), the browser will load forever.

Running the server

If we say there is a folder called Flags_Project which has a file called app.js inside, we could do the following: 

cd Flags_Project
node app.js

This would run app.js, but whenever a change is made in the file, it is needed to stop the server with Ctrl + C and run it again.

Luckily there is a faster way to run the server.

cd Flags_Project
nodemon app.js

The command "cd Flags_Project" is simply to change directory to the specific folder, and is only needed to be done if you're not already in the correct directory.

The important part of the above command is nodemon, which makes it possible to run the server without having to constantly re-run it.

Note that nodemon needs to be installed to work. Install nodemon from npm 

npm install -g nodemon

Server side redirect

app.get("/", (req, res) => {
  res.send({ data: "Frontpage" });  
});

app.get("/frontpageRedirect", (req, res) => {
  res.redirect("/");
});

Here the "/frontpageRedirect" redirects to "/".

Parsing JSON with Express

To parse JSON, you must first enable the express JSON-parser like so:

app.use(express.json());

It has to be right under your imports at the top of the file.

Query String

To read the query string, use req.query.

app.get('/flags', (req, res) => {
  res.send({ data: req.query });
});
http://localhost:8080/flags?country=China&symbol=stars

The end of the URL ('flags?country=China&symbol=stars') above is called the query string, which is a way to save information.

You can type the query string directly in your browser, and it will send it to the server, which reads it with req.query.

dirname

To avoid putting your exact path name, with your personal folders, in the program you should instead use __dirname. This only works in CommonJS, not ES Modules. 

app.get('/', (req, res) => {
  res.sendFile(__dirname + '/index.html');
});

For ES Modules, you instead use path.

import path from 'path';

app.get('/', (req, res) => {
  res.sendFile(path.resolve('index.html'));
});

When using path.resolve(), there shouldn't be a "/" in front of the first file/directory, as opposed to how it works with dirname.
