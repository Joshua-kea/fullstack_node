Introduction to starting a server

Express

Client/Server and app.js

Client sends a request (shortened to req), server sends a response (shortened to res). Use res.send(); to send a response back to the client. We use a generic data-type to send data. 

app.get('/', (req, res) => {
  res.send({ data: "Hello, how are you?" });
});

The example above is called a route. '/' is the endpoint, it could also have been '/flags' for example. (req, res) => {} is a an example of a callback function. Learn more about callback functions here res.send() sends a JavaScript object, which is parsed into json by the help of express. Without res.send(), the browser will load forever.

Running the server

If we say there is a folder called Flags_Project which has a file called app.js inside, we could do the following: 

cd Flags_Project
node app.js

This would run app.js, but whenever a change is made in the file, it is needed to stop the server with ^C and run it again.

Luckily there is a faster way to run the server.

cd Flags_Project
nodemon app.js

The command "cd Flags_Project" is simply to change directory to the specific folder, and is only needed to be done if you're not actively in the correct directory.

The important part of the above command is nodemon, which makes it possible to run the server without having to constantly re-run it.

Note that nodemon needs to be installed to work. Install nodemon from npm 

npm install -g nodemon

Server side redirect

app.get("/", (req, res) => {
  res.send(frontpage);  
});

app.get("/frontpageRedirect", (req, res) => {
  res.redirect("/");
});

Here the "/frontpageRedirect" redirects to "/".

Parsing JSON with Express

To parse JSON, you must first enable the express JSON-parser like so:

app.use(express.json());

It has to be right under your imports at the top of the file.

Query String

http://localhost:8080/bars/forgottenItems?wallet=200&keys=my_house&my_baby=Sam

The end of the URL ('forgottenItems?wallet=200&keys=my_house&my_baby=Sam') above is called the query string, which is a way to save information.

dirname

To avoid putting your exact path name, with your personal folders, in the program you should instead use __dirname. 

app.get('/', (req, res) => {
  res.sendFile(__dirname + '/index.html');
});
