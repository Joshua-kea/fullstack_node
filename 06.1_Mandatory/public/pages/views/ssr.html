Splitting up the HTML page

DRY (Don't Repeat Yourself) code is a general guideline when it comes to programming. The less your code repeats itself, the more reusable it is, and the less you'll have to fix everytime you make a change.

When it comes to SSR (Server Side Rendering) you will split up your HTML files, into sections that are repetitive. This will often be the header and the footer, but it can be other things such as a navigation bar.

You simply create a header.html and a footer.html, to put the content that all your HTML pages need, in those files.

Your header.html might look something like this:

<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="stylesheet" href="/assets/css/index.css" />

    <title>Document</title>
  </head>
  <body>
  <main>

And your footer.html might look something like this:

</main>

    <footer>© 2026</footer>
  </body>
</html>

Templating Engine

While it is possible to install templating engines, it is nice to create your own so you have full control of the content.

The first thing you'll want to do, is create a function that can read your HTML files.

import fs from "fs";
    export function readPage(path) {
  return fs.readFileSync(path, "utf-8");
}

We have an import from 'fs', which is a a part of the node library. It stands for File System, and is needed to read files.

The function above, simply reads a HTML file. It takes a path and utf-8 as an argument. You could also make it:

return fs.readFileSync(path).toString();

And it would be the same outcome.

The next step would be to create a function that can construct the page with header, content and footer.

export function constructPage() {
  const header = readPage("public/components/header/header.html");
  const footer = readPage("public/components/footer/footer.html");

return header + page + footer;
}

**Then later it can turn into something like:**

export function constructPage(page, options = {}) {
  const header = readPage("public/components/header/header.html");
  const footer = readPage("public/components/footer/footer.html");

  return (
    header
      .replace("{{CSS_LINKS}}", options.cssLink || "")
      .replace("{{TAB_TITLE}}", options.tabTitle || "Flags")
    + page
    + footer
  );
}
