Objects

  • Spread operator

An object is written with {}. It has key-value pairs.

const flag = {
  country: "Cyprus",
  color: "White",
  symbol: "Map of Cyprus"
};

Here the object is "flag". The country, color, and symbol are all keys. "Cyprus", "White", and "Map of Cyprus" are all values. You can dot your way into a specific value. 

console.log(flag.country);
// output is "Cyprus"

Spread operator

const flagOfPapuaNewGuinea = {
  country: "Papua New Guinea",
  color: "Red",
  color: "Black",
  color: "Multi",
  symbol: "Bird of paradise"
};

In this example the color is multi, since it is overwritten and the first two colors are ignored. 

const flagOfPapuaNewGuinea = {
  country: "Papua New Guinea",
  color: "Multi",
  symbol: "Bird of paradise"
};

const flagOfSeychelles = {
  country: "Seychelles",
  continent: "Africa",
  yearOfNationalFlag: 1996
};

console.log({...flagOfPapuaNewGuinea, ...flagOfSeychelles});
// output would be:
// { country: 'Seychelles', color: 'Multi', symbol: 'Bird of Paradise',
// continent: 'Africa', yearOfNationalFlag: 1996 }

By using the spread operator, it becomes one object. Therefore the keys that the 2 objects share, are overwritten by the last object, and the keys they don't share don't have their values overwritten.
