Introduction to learning HTML

HTML is the language the browser understands.

Creating your first HTML file

The very first thing you want to do is create a new file. Let's name it index. You want to make it an HTML file by calling it index.html.

You now have a blank page, and a smart way to start your HTML page is by simply writing "HTML" and a dropdown of options will show. Pick HTML:5, and you will receive a boilerplate HTML page.

Tags, IDs, and classes

Tags are inside of angle brackets <>, that could for example be a header in <h1>. 

<h1>Flags</h1>

IDs are inside the tag, to make it possible to access that specific element with either JavaScript or CSS. An ID is unique, and only 1 element should have that exact ID. 

<h1 id="firstHeaderID">Flags</h1>

Classes are inside the tag, to make it possible to access that specific element with either JavaScript or CSS. A class can be used on several elements, as a way to group them together. 

<h1 class="firstHeaderClass">Flags</h1>

Structure of an HTML file

<!doctype html> <!-- the document type is HTML -->
<html lang="en"> <!-- the HTML language is English -->
  <head> <!-- the <head> tag -->
    <meta charset="UTF-8" /> <!-- the set of characters the page uses -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <link rel="icon" href="/assets/images/favicon.png"> <!-- the favicon, aka the logo in the tab -->
    <link rel="stylesheet" href="/assets/css/index.css" /> <!-- link to the css file, for styling -->

    <title>Flags</title> <!-- Tab title -->

<!-- closing tags -->
</head> 
</html>

The <head> tag contains data that is not shown on the page.

When adding JavaScript <script> tags, it is important to think about the order in which they are loaded in. The HTML file is read from top to bottom, so if, for instance, you have flag.js which uses a function that is defined in country.js, then country.js needs to be loaded in HTML before flag.js is loaded. 

<script src="/country.js"></script>
<script src="/flag.js"></script>

If flag.js is loaded before country.js, then flag.js will fail, because the function from country.js doesn't exist yet.

XSS (Cross-Site Scripting)

XSS is when a person from the outside can add script to the website by for example putting their name as a script. This can be done with malicious intentions and cause major security issues.

To avoid XSS it is recommended to not use innerHTML, and instead make use of innerText. innerText will read everything as text and therefore any potential malicious script, will have no effect, as it won't run. If you need to use innerHTML, you can also create an escape HTML function. 

function escapeHTML(string) {
    return string
        .replaceAll('&', '&amp;')
        .replaceAll('<', '&lt;')
        .replaceAll('>', '&gt;')
        .replaceAll('"', '&quot;')
        .replaceAll(''', '&#39;')
        .replaceAll('`', '&#x60;')
        .replaceAll('/', '&#x2F;');
}

It is possible to download the escape HTML function from a library, but it can feel counterintuitive to trust another source for something that is supposed to protect you from outside scripts. If using a library, it is important to choose a well-maintained and widely trusted source. Libraries have the benefit of having been tested against edge cases and making sure, that your function doesn't accidentally have spelling errors or typos. It is a matter of preference.

Datalist

If you want an autocomplete dropdown for a searchbar, you can use the <datalist> tag. 

<!-- the search input -->
<input list="flags-list">

<!-- the datalist -->
<datalist id="flags-list">
  <option>Andorra</option>
  <option>Mozambique</option>
  <option>Dominican Republic</option>
</datalist>

Now if you search for "A" it will give a dropdown for all 3 countries, as they all have A in it. If you search "And" it will shorten the autocomplete to only have "Andorra".
