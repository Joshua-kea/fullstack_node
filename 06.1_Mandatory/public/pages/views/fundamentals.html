Introduction to learning the fundamentals of Node.js

var, let, and const

It is never recommended to use var, as it is function-scoped instead of block-scoped and can cause major bugs.

let can be used if you're creating a variable with a changing value.

The most commonly used way to declare a variable is with const. const stands for constant, and, as the name suggests it is a variable that is not later reassigned.

Side effects

Side effects is when code changes something unexpected, or something you didn't wish to change. 

for (var i = 0; i <= 5; i++) {
  setTimeout(() => {
    console.log(i)
  }, 1000);
}

This code snippet uses var in a for-loop. var ignores blocks. var is function-scoped, whereas let and const are block-scoped. There is only one i, and all 6 callbacks share it. The loop finishes before the first setTimeout runs, so i is already 6 when the callbacks log it. That means the log becomes 6 printed six times. 

for (let i = 0; i <= 5; i++) {
  setTimeout(() => {
    console.log(i)
  }, 1000);
}

The solution is as above: to use let instead of var. Here we will see the expected result of 0, 1, 2, 3, 4, 5. This is because let (and const) is block-scoped, meaning it is contained in the block. That means that every loop gets its own i, so each callback is able to remember its own value. 

{
  var someValue = 123;
    {
      var someValue = 456;
    }
  console.log(someValue)
}

Here we use var again. As we just saw in the previous example, var is function-scoped. Because of that, this example will be 456. The value is simply changed from 123 to 456. 

{
  let someOtherValue = true;
    {
      let someOtherValue = false;
    }
  console.log(someOtherValue)
}

In this example where we use let, the nested block is a different block-scope, where the value is its own, even if they share the same name.

Use strict

With use strict, it is possible to catch errors that otherwise wouldn't be caught, such as undefined variables. It is used by declaring "use strict"; to the beginning of a script or a function.

Naming conventions

Make sure functions and variables have readable and clear names. It is not recommended to use numbers in variable names. It is good practice to use the variable name first in a function or new variable that is about the first variable. For example: 

const countries = [
{ name: "Lesotho", gdp: 2.57 },
{ name: "Papua New Guinea", gdp: 34.40 },
{ name: "Saint Vincent and the Grenadines", gdp: 1.26 }

Math()

Math.floor rounds down, so the float becomes an int.

getRandomInt(5, 10);

function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1) + min);
} // returns a random int between min value and max value

To get a random int between 5 and 10, it is possible to use Math.random() and * it with max - min + 1 and then + min. It is possible to call the function before it has been declared, because of hoisting.

The difference between ++value and value++

let value = 1;
value++; // 1: returns the value, and then adds 1
value; // 2: returns the value
value++; // 2: returns the value and then adds 1

This will give 1, 2, 2. It reads the value, then adds 1. Then it reads the value, which is now 2. Then it reads the value, which is still 2, before it adds 1. 

let value = 1;
++value; // 2: adds 1, then returns the value
value; // 2: returns the value
++value; // 3: adds 1, then returns the value

This will give 2, 2, 3. It adds the 1 and then reads it, so it becomes 2. Then it reads the value, which is 2. Then it adds 1, and reads the value which is now 3.
