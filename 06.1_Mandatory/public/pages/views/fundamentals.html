var, let, and const

it is never recommended to use var, as it bleeds out and can cause major bugs.
let can be used if you're creating a variable with a changing value.
The most commonly used way to declare a variable is with const. const stands for constant, and, as the name suggest
it is an variable that is not later changed.

Side effects

for (var i = 0; i <= 5; i++) {
  setTimeout(() => {
    console.log(i)
  }, 1000);
}

This code snippet uses var in a for-loop. var bleeds out into the console.log(i) and therefor the result is unexpected. this specific piece of code will print 6 six times. This is because var is global. 

for (let i = 0; i <= 5; i++) {
  setTimeout(() => {
    console.log(i)
  }, 1000);
}

The solution is as above: to use let instead of var. Here we will see the expected result of 0, 1, 2, 3, 4, 5.
This is because let (and const) is block-scope, meaning it is contained in the block. 

{
  var someValue = 123;
    {
      var someValue = 456;
    }
  console.log(someValue)
}

Here we use var again. As we just saw in the previous example, var is global. Because of that, this example will be 456. the value is simply changed from 123 to 456. 

{
  let someOtherValue = true;
    {
      let someOtherValue = false;
    }
  console.log(someOtherValue)
}

In this example where we use let, the nested object is outside of the block-scope, and therefor the value will be true.

Naming conventions

Make sure functions and variables have readable and clear names. It is not recommended to use numbers in variable names.
It is good practice to use the variable name first in a function or new variable that is about the first variable.
For example: 

const countries = [
{ name: "Lesotho", gdp: 2.57 },
{ name: "Papua New Guinea", gdp: 34.40 },
{ name: "Saint Vincent and the Grenadines", gdp: 1.26 }
]

const countriesWithGDPUpdated = ...

Here the second const has countries as the first part of the name so it is quickly clear, that we're updating countries (the first const).

Math()

Math.floor runder op, så en float bliver til en int.

getRandomInt(5, 10);

function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1) + min);
}

To get a random int between 5 and 10, it is possible to use Math.random() and * it with max - min + 1 and then + min. It is possible to call the function before it has been declared, because of hoisting.

The difference between ++value and value++

Let 1;
Value++;
value;
Value++;

This will give 1, 1, 2 because the ++ is added after. So it goes 1, then just reads the value without adding anything, so 1 again, and then it's 2 because it added the value earlier. 

Let 1;
++Value;
value;
++Value;

This will give 2, 2, 3. It adds the ++ first. So 2, then it read the value: 2 again. Then it adds the ++ again which becomes 3.
