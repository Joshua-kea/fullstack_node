Functions

Functions are reusable code. In JavaScript you can pass a function as a parameter in a different function.

Using ';' is not needed for JavaScript, but I choose to use it both because I am used to it from Java, but also because I feel like the code looks nicer and more readable when using ;. It is worth noting that sometimes ; needs to be after }, so it becomes };. This is only for statements. Function declarations and blocks don't have ; after }

Ways to write a function

If you have a function like this:

function showFlag(country, formatter) {
  return formatter(country);
}

This function takes a country and a formatter, calls the formatter with the country as parameter, and returns the result.

There are many ways to write a function. Below are three examples.

function formatAsText(country) {
  return `This is the flag of ${country}`;
} // an example of a function declaration

console.log(showFlag("Togo", formatAsText));
// output is: This is the flag of Togo

const redFlag = (country) => {
  return `${country} has the color red in its flag`;
}; // an example of an arrow function

console.log(showFlag("Tonga", redFlag));
// output is: Tonga has the color red in its flag

console.log(showFlag("Equatorial Guinea", (country) => `${country} is in Africa`));
// an example of an inline function
// output is: Equatorial Guinea is in Africa

Anonymous functions

An anonymous function doesn't have a name on its own, like a function declaration does. Instead it is stored in a variable. 

const getRandomIntAnonymousFunction = function (min, max) {
  return Math.floor(Math.random() * (max - min + 1) + min);
}; // Anonymous function

const getRandomIntArrowFunction = (min, max) => {
  return Math.floor(Math.random() * (max - min + 1) + min);
}; // Arrow function

// Both functions return a random int between min value and max value

Callback functions

A callback function is a function that is passed as an argument to another function.

Callback functions can be compared to when you call customer service, and they offer an option to press 1 and they'll call you back when it's your turn, instead of you waiting on the line. That way you can do other things, while waiting for customer service to call you.

With a callback function, JavaScript can do other things, while waiting on a response, instead of stopping the program while waiting. A callback can be called, but it can also for example be an error handling where it may never be called, or only is called in specific scenarios. In the example below, the callback function is only ever called if someone accesses /flags. 

                 // this is the callback function
app.get('/flags', (req, res) => {
  res.send("Flags")
});

Hoisting

It is not strictly necessary to write JavaScript functions chronologically, meaning if you have function A that makes use of function B, then function B doesn't have to be declared first, it can be declared much later and the code will still work. This is because of hoisting.

This is only true for function declarations. Arrow functions, anonymous functions or variables need to be declared before they are used.
