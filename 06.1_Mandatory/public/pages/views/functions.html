Functions

Using ';' is not needed for JavaScript, but I choose to use it both because I am used to it from Java, but also because I feel like the code looks nicer and more readable when using ;. It is worth noting that sometimes ; needs to be after }, so it becomes };. But this is only the case for statements and not if it is a function.
Below there are 3 different examples of how to solve the same problem. 


      function genericActionPerformer(name, action) {
        return action(name);
      }

      function playingGuitarAction(name) {
        return `${name} likes to play guitar`;
      }

      console.log(genericActionPerformer("Elias", playingGuitarAction));

      const watchingMoviesAction(name) => {
        return `${name} likes to watch movies`
      };

      console.log(genericActionPerformer("Magnus", watchingMoviesAction));

      console.log(genericActionPerformer("Jacob", (name) => `${name} likes sailing`));

The last console.log is an example of a callback function.

Callback functions

Callback can be compared to when you call customer service, and they offer an option to press 1 and they'll call you back when it's your turn, instead of you waiting on the line. That way you can do other things, while waiting for customer service to call you. With a callback function, JavaScript can do other things, while waiting on a response, instead of stopping the program while waiting. Callback is a function reference that can be called as an argument. A callback *can* be called, but it can also for example be an error handling or an if/else statement, where it may never be called, or only is called in specific scenarios.
