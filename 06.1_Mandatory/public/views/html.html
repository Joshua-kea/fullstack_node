XSS (Cross-Site Scripting)

What is XSS?

XSS is when a person from the outside can add script to the website by for example putting their name as a script
This can be done with malicious intentions and cause major security issues.

How to avoid XSS

To avoid XSS it is recommended to not use innerHTML, and instead make use of innerText.
innerText will make everything in to a String and therefor any potential malicious script, will have no affect.
