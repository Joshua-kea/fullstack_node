Terminal commands

Shells

The shell is used to run commands.

The default shell on Linux and macOS is Bash. On Windows the default is powershell. The commands can differ slightly between shells.

Common Bash commands

  • ls lists directory contents
  • cd change current directory
  • cd .. return to the parent directory
  • cd - return to the previous directory
  • rm delete a file
  • rm -r delete a folder
  • mv move or rename a file
  • touch create a new file
  • mkdir create a new folder

Git commands

  • git add . stages all the files in the current directory
  • git add -A stages all the files in the whole repository
  • git commit -m "message" creates a commit with a message
  • git branch shows all local branches, and marks the current branch with *
  • git checkout -b "branch-name" creates a new branch
  • git push pushes to the remote repository

Node.js commands

  • node -v shows the installed Node.js version
  • npm init creates a package.json file
  • npm install <package-name> installs a package from npm
  • npm run <script-name> runs a package.json script
  • node app.js runs app.js once
  • nodemon app.js runs app.js and restarts it after file changes
