Terminal commands

Terminal commands can be run in any terminal, but personally I always use the powershell terminal in VS Code.
If we say there is a folder called Flags_Project which has a file called app.js inside, we could do the following: 


        cd Flags_Project
        node app.js

This would run app.js, but whenever a change is made in the file,
it is needed to stop the server with ^C and run it again.
Luckily there is a faster way to run the server. 


        cd Flags_Project
        nodemon app.js

The command "cd Flags_Project" is simply to change directory to the specific folder, and is only needed to be done if you're not actively in the correct directory.
The important part of the above command is nodemon, which makes it possible to run the server without having to constantly re-run it.
Note that nodemon needs to be installed to work. Nodemon can be installed here

npm install, cd .., git add ., git add -A, git branch, git commit -m "", git push, git branch -b "", ls
