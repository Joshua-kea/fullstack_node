Spread operator


        const labrador = {
          color: "brown",
          color: "white",
          color: "multi"
          energyLevel: 9.4
        };

In this example the color is multi, since it is overwritten and the first two colors are ignored. 


        const labrador = {
          color: "brown",
          color: "white",
          color: "multi"
          energyLevel: 9.4
        };

        const chihuahua = {
          energyLevel: 10.0,
          isScaredOfAnything: false
        };

        console.log({...labrador, ...chihuahua});

By using the spread operator, it becomes one object. Therefor the color is multi, but the enerygLevel would now be 10, as it overwrites the labrador's energyLevel.
