Introduction to learning CSS

CSS is how we style our website and stands for Cascading Style Sheets

Inline CSS

Inline CSS is when the styling is done directly in the HTML file, on the specific element.

<p style="background-color: lightblue; color: red;">A website about flags</p>

This will give you the following output:

A website about flags

For inline styling, you can easily style a specific element, but you can't easily re-use that styling. If all <p> elements have the same styling, you'll have to rewrite it for each paragraph.

External CSS

For external CSS you create a .css file, and keep the styling contained there.

External CSS is useful for several reasons. First of all, it makes the code re-usable. You can have your styling defined in one css file, and link it to several html files, instead of repeating the code. It also makes the code more readable, as you won't have styling on every element in your html file.

To connect the css style and the html file, you'll simply add a link in the html file.

<link rel="stylesheet" href="index.css">

Add the link inside of the header. You can name your css file as you wish. In this example I named it index. Remember to link to the correct path. If it is placed inside a css folder, remember to add that to the href path.
