Introduction to learning CSS

CSS is how we style our website and stands for Cascading Style Sheets.

Inline CSS

Inline CSS is when the styling is done directly in the HTML file, on the specific element.

<p style="background-color: lightblue; color: red;">A website about flags</p>

This will give you the following output:

A website about flags

For inline styling, you can easily style a specific element, but you can't easily re-use that styling. If several elements have the same styling, you'll have to rewrite it for each element.

External CSS

For external CSS you create a .css file, and keep the styling contained there.

External CSS is useful for several reasons. First of all, it makes the code re-usable. You can have your styling defined in one CSS file, and link it to several HTML files, instead of repeating the code. It also makes the code more readable, as you won't have styling on every element in your HTML file.

To connect the CSS file and the HTML file, you'll simply add a <link> element in the HTML file.

<link rel="stylesheet" href="index.css">

Add the <link> element inside of the <head> element. You can name your CSS file as you wish. In this example I named it index. Remember to link to the correct path. If it is placed inside a CSS folder, remember to add that to the href path.

To access an element with external CSS there are several ways to go about it.

HTML tags are easy to access:

body {
  /* styling would go here */
}

CSS selectors define which elements the styling applies to. There are many selectors to choose from.

#flag {
  /* this is how to style an element with the id="flag" */
}

.flag {
  /* this is how to style an element with the class="flag" */
}

a:hover {
  /* this is how to style the hover-effect of an <a> tag */
}

ul li {
  /* this is how to style a <li> tag inside of a <ul> tag */
}

CSS example

CSS offers a lot of options and possibilities for styling, but one example is how to create a proper footer.

If you use the HTML tag <footer> you might think it automatically behaves as a footer, and sits at the bottom of the page. However, this is not the case. It works like any HTML tag, and will simply sit where you place it. To make it look as we expect, the following CSS is needed:

body {
    min-height: 95vh;
    display: flex;
    flex-direction: column;
}

main {
    flex: 1;
}

The min-height is the minimum height of the body. Here it is set to 95vh. (vh is viewport height.) 100vh is the full height of the viewport. To make space for the margin, we use 95vh.

The display needs to be set to flex to make sure flex-direction works as intended. flex-direction is set to column, meaning the children are vertical. The opposite would be row, which is horizontal. Row is also the default.

A <main> tag is needed, to define the main content of the page. There should only ever be one per page. It needs flex: 1. This means that <main> takes up all the leftover space. So if there isn't enough content to fill the space, <main> will still stretch out to fill up the page, with empty content below.
