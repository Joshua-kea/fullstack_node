Errors & Debugging

Error is undefined, if it isn't set. Meaning, it is a false-value. A statement can not be shown if it is
falsy, it can only be shown if the statement is true. That is how a case like this works: 

if (error) {
  console.log("There was an error", error);
  return;
}
  console.log("Everything worked out as hoped.");

If you get an error such as:

Error: ENOENT: no such file or directory, stat 'C:\Users\you\fullstack_node\02_First_Serverindex.html'

You can write the following in the terminal:

C:\Users\you\fullstack_node\02_First_Serverindex.html

And see if you get the same error, then the file doesn't exist in that path. Maybe it's the wrong filename or path.
